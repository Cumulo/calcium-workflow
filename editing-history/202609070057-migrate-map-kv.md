# Migrate the session-message map transformation / 迁移会话消息 Map 转换

## English

- Replace the last application-owned legacy `map-kv` call with
  `filter-map-kv`.
- Return `MapEntryDecision :keep` explicitly and narrow the callback schema to
  `MapEntryDecision<String, Component>`.
- Preserve the existing message identifiers, rendered components, ordering,
  and final `.to-list` conversion.

Verification:

- Calcit `0.13.78-rc.1` default/client `--check-only`
- Calcit `0.13.78-rc.1` server-entry `--check-only`
- Calcit `0.13.78-rc.1` JavaScript generation

## 中文

- 将应用自身最后一处旧 `map-kv` 调用替换为 `filter-map-kv`。
- 显式返回 `MapEntryDecision :keep`，并将 callback schema 收紧为
  `MapEntryDecision<String, Component>`。
- 保持原有消息 id、渲染组件、顺序以及最终 `.to-list` 转换不变。

验证：

- 使用 Calcit `0.13.78-rc.1` 通过 default/client `--check-only`
- 使用 Calcit `0.13.78-rc.1` 通过 server entry `--check-only`
- 使用 Calcit `0.13.78-rc.1` 完成 JavaScript 生成
